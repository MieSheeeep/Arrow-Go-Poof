# 核心设计 README 设计

## 目标

将仓库根目录 `README.md` 改写为面向开发与评阅的简洁项目说明：不使用图片，不重复课程博客的开发过程，准确说明玩法、核心架构、关键约定、运行与测试方式。

## 内容结构

1. 项目简介：Python + Pygame 箭头解谜游戏和一句玩法概述。
2. 快速开始：Python 版本、依赖安装、启动和测试命令。
3. 核心玩法：不规则棋盘、四种箭头、路径检测、成功与阻挡结果。
4. 核心设计：Board / Game / Animation / UI 的职责与数据流。
5. 关键约定：`None` 与 `.` 的含义、成功立即改写逻辑棋盘、提示复用规则层、动画只做视觉、按本关总分比例结算 1–3 星。
6. 项目结构：只列出运行和核心源码/测试目录。
7. 文档链接：课程报告、测试计划和 AIGC 记录。

## 规则准确性

- `None` 表示图案外边界；路径到达它即可飞出。
- `.` 表示已清除的有效格，可被路径穿过。
- 首个 `U/D/L/R` 是 blocker；成功点击立即把当前位置改为 `.`。
- 星级按照单关得分占理论最高分的比例结算：85% 为 3 星、60% 为 2 星，其余为 1 星。
- 倒计时只负责超时失败；阻挡通过重置 Combo 间接影响得分。
